# 0002: style tile approved

Date: 3 November 2026.

The owner rejected the first style tile ("a little simple WordPress tile layout 101 rather than a maturely designed, thought-through page"; typography and layout) and approved the second, recomposed on a reference-work grid: a margin column beside a main column, three composed pages, full-bleed panel plates with hairline rows, ruled option cells.

From this point `design/style-tile.html`, generated by `scripts/build-style-tile.mjs` from `design/tokens.css`, is the source of truth for the visual design, as `docs/design-direction.md` describes. Changes to the look go through the tile first: regenerate, screenshot at phone and laptop widths, critique, then carry the change into `src/styles`.

Also decided the same day: both published datasets may be downloaded for the norms tables (Johnson's IPIP-NEO-120 data on OSF, and the openpsychometrics.org IPIP-FFM 50-item data). They live in the gitignored `data-raw/` folder; the repository commits only the generated count tables and the SHA-256 of each input.
